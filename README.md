# 🌙 Amalin — Panduan Amalan Setelah Sholat dalam Satu Tempat

> **Tagline:** Panduan Amalan Setelah Sholat dalam Satu Tempat.  
> **Masalah yang diselesaikan:** Tidak perlu lagi bolak-balik mencari doa atau urutan dzikir di TikTok, Instagram, atau Google. Selesai sholat, cukup buka Amalin dan ikuti alurnya dari awal hingga akhir.

---

## ✨ Fitur Utama

1. **🕌 Sholat Wajib (5 Waktu Fardhu)**
   - Subuh, Dzuhur, Ashar, Maghrib, Isya.
   - Dilengkapi alur ma'tsur: Istighfar, Allahumma Antas Salam, Tahlil 10x (Subuh & Maghrib), Doa perlindungan neraka (7x), Tasbih 33x, Tahmid 33x, Takbir 33x, Ayat Kursi, Surat Al-Mu'awwidzat (3 Qul), dan doa penutup.

2. **🌙 Sholat Sunnah Muakkadah**
   - Tahajud, Dhuha, Taubat, Witir, Hajat, Istikharah.
   - Contoh **Tahajud**: Doa Bangun Malam / Iftitah Tahajud $\rightarrow$ Sayyidul Istighfar $\rightarrow$ Tasbih 100x $\rightarrow$ Doa Ampunan & Rezeki $\rightarrow$ Doa Kemudahan Urusan & Ortu $\rightarrow$ Sholawat Ibrahimiyyah.
   - Contoh **Dhuha**: Doa Dhuha $\rightarrow$ Dzikir Istighfar Dhuha 100x $\rightarrow$ Ayat Seribu Dinar $\rightarrow$ Doa Kelapangan Rezeki Halal.

3. **🤲 Doa Pilihan Terpenting**
   - Doa Nabi Yunus AS (Dzun Nun)
   - Doa untuk Kedua Orang Tua
   - Ayat Seribu Dinar (At-Talaq 2-3)
   - Ayat Kursi (Al-Baqarah 255)
   - Sholawat Munjiyat
   - Doa Sebelum & Bangun Tidur
   - Doa Sebelum & Sesudah Makan
   - Doa Keluar & Masuk Rumah
   - Doa Sapu Jagad
   - Sayyidul Istighfar & Doa Menghilangkan Hutang / Galau

4. **⭐ Mode Terpandu (Guided Alur Langkah demi Langkah)**
   - Fitur unggulan: tombol *"Mulai Mode Terpandu"* menyajikan doa langkah demi langkah dengan progress bar dan tombol "Lanjut", bebas distraksi setelah sholat.

5. **📿 Digital Tasbih Counter Terintegrasi**
   - Menghitung dzikir (33x atau 100x) langsung di layar.
   - Visual progress bar, haptic vibration feedback pada smartphone, dan opsi klik audio lembut.

6. **🔍 Instant Search (Ctrl + K)**
   - Pencarian cepat mencari sholat, doa, topik seperti "rezeki", "yunus", "tahajud", "maghrib", "ortu", "hutang", dll.

7. **❤️ Favorit (Local Storage)**
   - Simpan doa atau sholat yang sering dibaca. Tersimpan langsung di browser tanpa perlu registrasi atau login.

8. **🌗 Dark Mode & Pengaturan Tampilan**
   - Mode gelap & terang otomatis tersimpan.
   - Atur ukuran font Arab (SM, MD, LG, XL).
   - Opsi sembunyikan/tampilkan teks Latin dan Terjemahan.

9. **📱 Mobile-First Responsive & Elegan**
   - Tampilan bersih, tipografi font kaligrafi Arab yang nyaman dibaca, dan tombol salin/bagikan satu klik.

## 💻 Tech Stack

- **React 18** (Vite)
- **Tailwind CSS** (dengan class dark mode dan palet Emerald-Gold islami modern)
- **React Router v6**
- **Lucide React** (Modern Iconography)
- **Local Storage** (Favorit, Dark Mode, Pengaturan Bacaan)
- **Data JSON Terstruktur** (referensi shahih hadits Bukhari, Muslim, Abu Daud, Tirmidzi, dll.)

---

## 🚀 Cara Menjalankan Proyek

1. **Install dependensi:**
   ```bash
   npm install
   ```

2. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Aplikasi dapat diakses di browser pada `http://localhost:5173`.

3. **Build untuk production:**
   ```bash
   npm run build
   ```

## 📚 Format Bacaan Konsisten

Setiap doa dan amalan disajikan dengan standar:
- 📖 **Arab**: Kaligrafi berharakat jelas.
- 🔤 **Latin**: Transliterasi mudah dibaca.
- 🇮🇩 **Terjemahan**: Bahasa Indonesia yang santun.
- ✨ **Keutamaan**: Fadhilah dan manfaat amalan.
- 📚 **Dalil & Referensi**: Riwayat hadits shahih & ayat Al-Qur'an.
